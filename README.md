# GATEFLIX

A Netflix-style single-page streaming site for **GATE (Season 1, Episode 1)** — Hindi dubbed.

Open the site: https://modijiff65-sys.github.io/gateflix/

## What's inside

| File | Purpose |
|---|---|
| `index.html` | The whole site — hero, episode row, custom player, download |
| `gate-ep1.mp4` | The episode, 854x480, 23:43, ~71 MB |
| `hero.jpg`, `thumb.jpg`, `thumb2.jpg` | Artwork pulled from the episode |

## Notes

- Hindi audio is AI-generated (Piper TTS, 3 voices across 4 detected speakers).
- English captions are burned into the video.
- Video is served from GitHub Pages; the Download button saves the same file.
